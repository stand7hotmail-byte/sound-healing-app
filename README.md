# ヒーリングサウンド — 音で心を整えるAndroidアプリ

ソルフェジオ周波数・自然音・脳波同調音を生演奏するリラクゼーションアプリ。

## 機能

### 🎵 ソルフェジオ周波数（9種類）
| 周波数 | 効果 |
|--------|------|
| 174 Hz | 疼痛軽減・身体の緊張緩和 |
| 285 Hz | 組織修復・細胞レベルの回復 |
| 396 Hz | 解放と浄化・恐怖心の解消 |
| 417 Hz | 変化を促す・ネガティブパターンの打破 |
| 528 Hz | 愛と奇跡・DNA修復（奇跡の周波数）|
| 639 Hz | 調和と関係・人間関係の改善 |
| 741 Hz | 浄化と解毒・思考の整理 |
| 852 Hz | 直観と霊性・第六感の覚醒 |
| 963 Hz | 神性への接続・完全な調和 |

### 🌧️ 自然音（5種類）
- 雨音 — 穏やかな降雨のホワイトノイズ
- 海浪 — モジュレートされた波の音
- 森林 — 葉ざわめきと鳥の声
- 風 — そよ風の低音ノイズ
- 溪流 — 小川のせせらぎ

### 🧠 脳波同調音（バイノーラルビート）
- デルタ波 (0.5–4 Hz) — 深い睡眠・回復
- シータ波 (4–8 Hz) — 瞑想・浅い睡眠
- アルファ波 (8–13 Hz) — リラックス・集中
- ベータ波 (13–30 Hz) — 覚醒・問題解決

## ビルド方法

```bash
cd sound-healing-app
./gradlew assembleDebug
```

APKは `app/build/outputs/apk/debug/app-debug.apk` に出力されます。

## デバイスへのインストール

```bash
./gradlew installDebug
```

またはAndroid StudioからRunボタンをクリック。

## 技術スタック

| 項目 | 技術 |
|------|------|
| 言語 | Kotlin |
| UI | Jetpack Compose + Material 3 |
| オーディオ | AudioTrack（リアルタイム正弦波生成）|
| 状態管理 | ViewModel + StateFlow |
| 最小SDK | 24 (Android 7.0+) |
| ターゲットSDK | 34 |

## 注意事項

- バイノーラルビート（脳波同調音）は**ヘッドホン必須**です
- 音量は安全範囲（最大30%）に制限されています
- 長時間の使用は控え、気分が悪くなったらすぐに停止してください
