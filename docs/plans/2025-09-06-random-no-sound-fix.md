# ランダム再生音なし修正計画

**Created**: 2025-09-06
**Status**: IN PROGRESS

## 問題
- ランダムタブで再生ボタンを押しても音が聞こえない

## 調査結果
1. エミュレータ入力問題: タップ検出不具合
2. startWithDelay使用: 最大5秒遅延

## 修正内容
- `startWithDelay` → `start` に変更（即時再生）
- 遅延を除去し、即座に音声生成を開始

## 検証基準
- [ ] ビルド成功
- [ ] インストール成功
- [ ] ログに `Start playing` 出力
- [ ] 音が聞こえる

## 次回テスト

- カード3つ選択
- 再生ボタン押下
- 音が聞こえるか確認
